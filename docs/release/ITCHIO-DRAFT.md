## Short description

A surreal action game where a sentient phone fights, captures loose souls, and spends them to break through shifting digital rooms.

## Page description

You are the phone.

Move through stark procedural rooms, crack hostile shells, pull exposed souls into the screen, and fire captured data back into the architecture. Every room asks you to balance movement, battery power, close-range attacks, precision, and the strange machinery living inside the device.

This Windows release candidate contains the current solo game and is being published for hands-on compatibility and gameplay testing. Expect an evolving build and clearly documented known issues.

### Current features

- Fast third-person movement built around jumps, lunges, ledges, and a physical phone body
- Vacuum-based soul capture and stored-soul projectiles
- Room goals, persistent upgrades, run modifiers, and battery management
- Keyboard/mouse and controller input
- Distinctive audiovisual presentation

Only mention online multiplayer here after the production service and privacy behavior pass release acceptance.

## Controls

- WASD: move
- Mouse: look
- Shift: sprint
- Space: jump
- Left mouse: vacuum
- F: melee
- Q: fire stored soul
- C: toggle first/third-person camera
- Tab: release mouse
- Escape: pause/quit
