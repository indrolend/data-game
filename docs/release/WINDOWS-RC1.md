# DATA — Windows release candidate

Run `DigitalBreakdown.exe` from this directory. Keep the `audio`, `fonts`, `models`, and `tv-gifs` directories beside the executable.

This is a prerelease build intended for compatibility and gameplay testing. If it fails to launch, include `build-info.json`, your Windows version, graphics hardware, and the steps immediately preceding the failure in the bug report.

The game stores local progression under the current Windows user profile. Online play requires a network connection and may be unavailable while the multiplayer service is offline.

See `THIRD-PARTY-NOTICES.md` and the `licenses` directory for bundled dependency notices.
