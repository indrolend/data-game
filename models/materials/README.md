# Photographic material sources

These deliberately literal real-world surfaces are from ambientCG and are
available under the CC0 1.0 license. Attribution is not required, but the
sources are retained here so the game's visual ingredients remain auditable.

| Runtime material | ambientCG asset | Source |
| --- | --- | --- |
| `photo-grass` | Grass001 | https://ambientcg.com/view?id=Grass001 |
| `photo-bark` | Bark014 | https://ambientcg.com/view?id=Bark014 |
| `photo-stone` | Rock064 | https://ambientcg.com/view?id=Rock064 |
| `photo-metal` | MetalWalkway014 | https://ambientcg.com/view?id=MetalWalkway014 |
| `photo-sand` | Ground054 | https://ambientcg.com/view?id=Ground054 |
| `photo-sterile-tile` | Tiles140 | https://ambientcg.com/view?id=Tiles140 |

The checked-in PNGs are 512 x 512 visual source references derived from each
asset's 1K JPG color map. The `.rgb` files (including the explicitly named
`*-runtime.rgb` copies) are vertically flipped, headerless 512 x 512 RGB
runtime data used by the native fixed-function renderer.
